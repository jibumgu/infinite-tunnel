# 무한 터널 (Infinite Tunnel)

스크롤로 끝없이 들어가는 착시 패럴럭스 웹입니다. 파스텔 그라데이션 5가지 버전이 있고, HTML 한 파일(Canvas)로만 만들어서 외부 라이브러리나 빌드 과정이 필요 없습니다.

## 버전

| 번호 | 이름 | 설명 |
|---|---|---|
| 1 | 체크 터널 | 구불구불 휘어진 체크무늬 사각 터널 |
| 2 | 별 터널 | 소용돌이치는 별 모양 띠 |
| 3 | 모래시계 | 줄무늬가 미끄러지는 모래시계 곡면 |
| 4 | 계단 | 울퉁불퉁 일렁이는 끝없는 계단 (체크무늬, 폭 변화, 좌우 구불거림) |
| 5 | 사다리 | 앞뒤가 엮이는 불가능한 사다리 3겹 (시차) |

## 조작

| 입력 | 동작 |
|---|---|
| 휠 위/아래, 터치 상하 드래그 | 앞뒤로 이동 |
| 휠 좌/우, 터치 좌우 드래그 | 회전 (4번 계단은 시야 좁히기/넓히기) |
| 방향키 ↑ ↓ | 앞으로 / 뒤로 (휠과 반대 방향) |
| 방향키 ← → | 회전 (4번은 시야각) |
| 숫자키 1~5, 하단 버튼 | 버전 전환 |

- 버전마다 위치와 회전이 따로 저장됩니다.
- 스크롤하지 않을 때는 움직이지 않습니다.
- 반응형입니다. 데스크톱, 태블릿, 폰(세로·가로)에 맞춰 화면과 버튼 크기가 바뀌고, 폰에서는 한 손가락으로 드래그하거나 튕겨서(관성) 움직일 수 있습니다.
- 마지막으로 본 버전은 브라우저(localStorage)에 기억됩니다.

## 구조

```
index.html          페이지 뼈대
css/style.css       스타일 (버튼, 반응형)
js/core.js          공용 상태, 그리기 도구, 입력(휠·터치·키보드)
js/modes/*.js       버전별 그리기 (checker, star, hourglass, stairs, ladder)
js/main.js          버전 전환 버튼, 상태 저장, 시작
```

새 버전을 추가하려면 `js/modes/`에 `setup`과 `draw`를 돌려주는 파일을 만들고, `index.html`의 `js/main.js` 앞에 `<script>`를 한 줄 추가한 뒤 `js/main.js`의 `NAMES`에 이름을 넣으면 됩니다. 숫자키 전환은 1~5까지로 정해져 있으니 6개 이상이면 `main.js`도 고치세요.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 로컬 서버가 필요하면 아래처럼 실행하세요.

```bash
python3 -m http.server 8000
```

GitHub Pages로 올리려면 저장소 설정의 Pages에서 `main` 브랜치 루트를 선택하면 됩니다.
